## 🌸 О проекте

Привет-привет! 👋 Это маленький, но гордый репозиторий про **управление перевёрнутым маятником** в симуляторе **PyBullet** 🧸

Тут живут:

- 🧲 физика, которая честно считает гравитацию,
- 🧮 математика, которая честно считает матрицы,

## 🧠 Как это работает

### 🪐 Физика

Классический перевёрнутый маятник. Уравнение движения:

$$
mL^2 \ddot{\theta} = -mgL\sin\theta + \tau
$$

где:

- $\theta$ — угол 🎣
- $\tau$ — момент, который мы прикладываем 💪
- $m = 1$ кг, $L = 0.8$ м, $g = 10$ м/с²

### 📐 Линеаризация

Возле вертикали $\sin\theta \approx \theta$, и получается милая линейная системка:

$$
\dot{X} = AX + B\tau, \qquad
A = \begin{bmatrix} 0 & 1 \\ -\frac{g}{L} & 0 \end{bmatrix}, \qquad
B = \begin{bmatrix} 0 \\ \frac{1}{mL^2} \end{bmatrix}
$$

### 🧮 LQR

Дальше — магия оптимального управления: минимизируем

$$
J = \int_0^\infty \left( X^\top Q X + R\tau^2 \right) dt
$$

И получаем матрицу усилений $K$, после чего живём по закону:

$$
\tau = KX = K_\theta \theta + K_\omega \omega
$$

В коде это буквально две строчки:

```python
Q = np.array([[1e3, 0], [0, 1e-2]])
R = 1e-2
K, *_ = lqr(A, B, Q, R)
K = -K  # 💫 потому что PyBullet и математики договорились не сразу
```

> 🧠 $Q$ говорит: «угол важен!», $R$ говорит: «не трать момент зря!».
> Меняешь их — меняешь характер маятника. Прямо как в жизни 💅

## 🎛 Три контроллера — три судьбы

В `pendulum.py` заботливо оставлены **три** варианта управления. Один включён, два ждут своей минуты славы 🌟

| Контроллер | Строка в коде | Характер |
|---|---|---|
| 🟣 **LQR** | `tau = K[0,0]*th + K[0,1]*vel` | Умный, оптимальный, включён по умолчанию |
| 🔵 **PID** | `dth = -kp*e - ki*e_int - kd*de` | Классика, надёжный дедушка |
| 🟢 **Линеаризация обратной связью** | `tau = (m*L*L)*(g/L*np.sin(th) - kp*e - kd*vel)` | Красивый, физичный, для эстетов |

Чтобы попробовать другой — просто раскомментируй нужную строчку и закомментируй LQR 😉

### Настройки по умолчанию 🎚

| Параметр | Значение | Смысл |
|---|---:|---|
| `th0` | `0.1` рад | стартовый угол |
| `thd` | `1.0` рад | куда хотим приехать |
| `dt` | `1/240` с | шаг симуляции |
| `maxTime` | `5` с | длительность опыта |
| `kp / ki / kd` | `40 / 40 / 20` | коэффициенты PID |

## 📈 Что видно на графиках

После запуска рисуются три панельки:

1. 📍 **Положение** — синяя линия (симуляция) против красного пунктира (цель).
2. 🌀 **Скорость** — как быстро маятник летит к своей мечте.
3. ⚡ **Момент** — сколько силы мы потратили на этот спектакль.

Хороший результат выглядит так: кривая красиво выходит на цель, скорость затухает, момент не улетает в космос 🚀❌

> В конце файла есть ещё блок с `odeint` — это заготовка для сравнения симуляции с численным интегрированием. Можно раскомментировать и посчитать ошибку ($L_2$ или $L_\infty$) — идеальный повод для отчёта 📝

## 🧪 Идеи для экспериментов

- 🎯 Поменять `thd` и посмотреть, как далеко маятник готов дотянуться.
- ⚖️ Поиграть с $Q$ и $R$: получить «ленивый» и «агрессивный» LQR.
- 🧵 Включить PID и честно сравнить с LQR по метрикам.
- 🌬 Добавить внешнюю силу `f0` и проверить, выстоит ли регулятор.
- 📉 Посчитать $L_2$ и $L_\infty$ ошибки между симуляцией и `odeint`.
